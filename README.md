# Топ пісень Spotify в Україні

Невеликий React-застосунок із таблицею популярних пісень. Натисніть на пісню,
щоб відкрити модальне вікно з її обкладинкою, виконавцями та подробицями.

## Запуск проєкту

Встановіть залежності:

```sh
npm install
```

Запустіть локальний сервер:

```sh
npm run dev
```

Перевірте код і зберіть проєкт:

```sh
npm run lint
npm run build
```

## Де шукати код

- `src/components/Table/Table.jsx` — список пісень і таблиця.
- `src/components/SongModal/SongModal.jsx` — вміст модального вікна.
- `src/assets/songImages.js` — обкладинки альбомів і фото виконавців.
- `src/index.css` та файли `*.style.js` — стилі застосунку.
